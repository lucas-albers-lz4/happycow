# Variant: Deal-First

## Design stance
The app's real job is "get me a drink before happy hour ends" — so the most time-sensitive deal is pinned at the top and every distraction (games, collection) is demoted below the fold or into a bottom tab.

## Key choices
- Layout: single-column, deal-first — pinned "Ending Soonest" card under the header, then decision shortcuts, then filters, then list
- Typography: system stack, bold names, small muted tags
- Color: existing cream/leather tokens; gold gradient pin card; green LIVE / gold soon / grey closed status bars
- Interaction: multi-select vibe chips with count badge, sort dropdown (closing/cheapest/A–Z), skeleton loaders, bottom tab bar, herd collection bottom-sheet, dark-mode toggle

## Trade-offs
- Strong at: fastest path to a decision; time-sensitive framing (closes-in countdown); familiar mobile app patterns
- Weak at: hides the whimsy that makes the site distinctive — the games are one tap away but the cow personality is quieter

## Best for
- The "I want a drink right now" user, and as the safe default home screen for a redesign
