# Variant: Cow-pare

## Design stance
When torn between two spots, put them side-by-side — hours, noise, tags, specials — and let the cow crown a lean winner.

## Key choices
- Layout: dual selects → two comparison columns with VS badge → winner banner
- Interaction: changing either select re-renders; winner heuristic prefers LIVE, then closes-sooner, then price
- Color: spot vs green column accents

## Trade-offs
- Strong at: decisive 1v1 moments
- Weak at: doesn't scale past 2 venues; noise tags are sketch-only

## Best for
- A detail action ("compare") off venue cards in Deal-First / Mood Board
