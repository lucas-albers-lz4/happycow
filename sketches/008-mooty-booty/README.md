# Variant: Moo-ty Booty

## Design stance
When nobody can decide, spin. A carnival wheel of *currently live* venues turns indecision into theater.

## Key choices
- Layout: pointer + canvas wheel → spin CTA → result card
- Interaction: ease-out spin (~3.2s); pool filtered to LIVE at demo clock
- Color: warm segment palette; gold wheel ring; cow hub

## Trade-offs
- Strong at: fun, shareable, kills deadlock
- Weak at: pure chance — bad if the user has hard constraints (budget, vibe)

## Best for
- The "Surprise Me" escalation from Deal-First shortcuts
