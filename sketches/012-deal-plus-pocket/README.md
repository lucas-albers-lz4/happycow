# Variant: Deal + Pocket (synthesis alt)

## Design stance
Same synthesis as **011**, different chrome: keep the bottom bar quieter (3 tabs), put **"Spin the herd"** on the home as the entertaining shortcut, and make Cow-pare a tiny icon so cards stay clean.

## vs 011

| | 011 Form Follows Fun | 012 Deal + Pocket |
|---|---|---|
| Spin | Own bottom tab | Big home shortcut under the pin |
| Vibe | Bottom tab → sheet | Same |
| Cow-pare | Full "Compare" button on card | Tiny `⇄` icon in the card header |
| Crawl | More → Plan a crawl | Same (buried) |
| Tabs | Deals · Vibe · Spin · More | Deals · Vibe · More |

## Why this alt exists
Spin-as-tab (011) makes fate-picking a first-class peer of Deals. Spin-as-shortcut (012) keeps personality on the home *without* adding a fourth tab — closer to "entertaining but not competing."

## Best for
- Head-to-head with 011 on: where should Spin live? How small can Compare get?
