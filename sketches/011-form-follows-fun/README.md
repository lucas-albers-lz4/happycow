# Variant: Form Follows Fun (synthesis)

## Design stance
**Deal-First is the spine.** The job — find a drink before happy hour ends — owns the viewport. Entertaining and ridiculous extras live in the bottom chrome so they never compete with the pin + list.

## What this folds in (from your feedback)

| Source | How it lands here |
|---|---|
| **001 Deal-First** | Pinned ending-soonest, sort, venue list front and center |
| **002 Vibe** | Bottom **Vibe** tab → mood sheet; active vibe is a clearable pill, not a permanent chip row |
| **003 Crawl** | **More → Plan a pub crawl** — useful, fully hidden until needed |
| **007 Cow-pare** | Tiny **Compare** on each card → slim tray above the tab bar (only when selecting) → sheet for the 1v1 |
| **008 Spin** | Bottom **Spin** tab → "Spin the herd" one-tap picker over live venues |

## Bottom chrome

`Deals · Vibe · Spin · More`

- **Deals** — home, always the default after a sheet closes
- **Vibe** — search-by-mood sheet
- **Spin** — ridiculous fate picker
- **More** — crawl planner, quiz, herd, horoscope

## Trade-offs
- Strong at: form follows function; personality still one tap away; compare/crawl cost zero permanent space
- Weak at: four tabs is busy; Spin as a tab is louder than a shortcut (see 012 for the alternate)

## Best for
- The leading candidate to promote if the synthesis direction sticks
