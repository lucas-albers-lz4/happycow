# Variant: Mooch List

## Design stance
Surface value, not just "open now" — a podium + cowbell leaderboard ranks bang-for-buck so moochers know where the herd gets the most.

## Key choices
- Layout: gold/silver/bronze podium → ranked list with cowbell ratings
- Scoring: cowbells ÷ drink price (2-for-1 deals get an effective price)
- Color: metallic podium gradients; spot-colored prices

## Trade-offs
- Strong at: glanceable "where should the cheapskates go"
- Weak at: needs trustworthy prices + subjective cowbell ratings (sketch is curated)

## Best for
- A secondary screen / sort mode, not the primary home
